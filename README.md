# Bitvavo AI Trader

## Version

v0.1.0 Foundation

---

## Project

Bitvavo AI Trader is een professionele AI-ondersteunde crypto tradingbot.

Het systeem is ontworpen volgens een "Quality First" ontwikkelmethode.

Live trading wordt pas geactiveerd nadat alle modules volledig getest zijn.

---

## Current Features

- FastAPI
- Docker
- PostgreSQL
- Redis
- Telegram
- Market Collector
- Indicator Engine
- Signal Engine
- Paper Trading

---

## Development Strategy

Quality First

We ontwikkelen volgens vaste sprints.

Elke module doorloopt:

1. Design
2. Development
3. Testing
4. Documentation
5. Git Commit
6. Merge naar main
